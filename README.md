# Add photographs here (optional)

All features work without photographs. These filenames are already connected to illustrated Memory Museum cards and surprise reveals:

- chips-date.jpg — first meeting / chips date (August 25)
- first-best-photo.jpg — first favourite picture (November 22)
- family-photo.jpg — photo together in front of the family (December 5)
- trio-cafe.jpg — Trio Café (May 31)
- birthday-memory.jpg — birthday and Darkhaast dance memory (December 25)

Keep filenames exactly as shown, using lowercase letters. Or edit `photo` entries in `assets/data.js` to match your pictures.

**Privacy reminder:** Photos committed to a public GitHub repository and hosted through GitHub Pages can be seen and downloaded by anyone with access to the repository or URL. Get permission before uploading intimate or private photos.
